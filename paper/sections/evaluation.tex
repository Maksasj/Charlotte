\section{Evaluation}

\paragraph{The check.} Answer steps are aligned to gold steps by (action, object), in order, using ground-truth aliases. Scoring then works as follows:
\begin{itemize}
  \item A \emph{strict pass} needs every needed item, every step and every order fact.
  \item A strict pass allows no wrong claim. Wrong claims are a different time, setting or amount; a reversed order; and use of an item the user lacks.
  \item A strict pass allows no extra steps or items, so dumping facts cannot pass.
  \item Graded recall and precision over all facts are reported beside it.
\end{itemize}
Negative controls are part of the test suite: a missing step, an extra step, a wrong order, a fact dump and a lacked item each fail.

\paragraph{The held-out set H3.} It was written from a specification by sub-agents that never saw the agent's code. It was then sealed by a SHA-256 manifest that a test checks. Its tiers are:
\begin{itemize}
  \item \textbf{S:} \hThreeS{} new situations on known tasks;
  \item \textbf{T:} \hThreeT{} new tasks in known domains, each with two variants;
  \item \textbf{G:} \hThreeG{} new gardening tasks plus the 5 gardening tasks removed from training. Gardening is a domain the agent never saw.
\end{itemize}
H3 is read three times at most, and only counts are shown until the final reading. An algorithmic tier repeats random 80/20 task splits, with the parser retrained without the test tasks.

\paragraph{Baselines.} Three baselines are run:
\begin{itemize}
  \item \textbf{B1:} the agent without adaptation (retrieval of the taught procedure);
  \item \textbf{B2:} Haiku given the teach lines and the request, answering in the same relation lines;
  \item \textbf{B3:} the unchanged v2.0.0 agent on the same scenarios, its English replies read back by the 3.0 parser. Read-back is lossy, so B3 is a lower bound.
\end{itemize}

\paragraph{Statistics.} Rates are reported with Wilson 95\% intervals. Paired comparisons use an exact McNemar test.

\paragraph{Cost.} Every Haiku call is cached by its input and archived, so a repeated run costs nothing. In total, \haikuCalls{} live calls were used.
