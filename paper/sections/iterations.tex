\section{Three iterations}

\subsection{Version 1: a symbolic core that could not represent doing}
Version 1 built a Datalog vault, a rule-based parser for short sentences and a reasoner with proofs. On its own fixed tests it was near perfect: \vOneKnowledgeHeldout\% of held-out knowledge tests passed. In real conversation it was not:
\begin{itemize}
  \item in the newest help-style training run, only \vOneRealAnswers{} of \vOneRealAnswersOf{} replies was a real answer;
  \item understanding fell to \vOneHelpUnderstood\% on help requests;
  \item the LLM translator, added late, invented \vOnePredicates{} distinct predicates.
\end{itemize}
The diagnosis was that the agent had been built and tested on facts, while helping is about \emph{doing}: tasks, steps, items and order.

\subsection{Version 2.0: procedures, a curriculum and its pitfalls}
Version 2.0 added procedures (tasks, steps, needs, times and order), a dialogue curriculum in which Haiku played user, teacher and judge, and many transfer mechanisms. The only clean reading of its held-out set was the first:
\begin{itemize}
  \item second encounter \vTwoCleanSecond{} of \vTwoCleanSecondOf;
  \item transfer \vTwoCleanTransfer{} of \vTwoCleanTransferOf;
  \item retention \vTwoCleanRetention{} of \vTwoCleanRetentionOf.
\end{itemize}
After many fixes chosen against those same 20 scenarios, the development-set numbers reached \vTwoDevSecond{}, \vTwoDevTransfer{} and \vTwoDevRetention{}. The 2.0 report found three things:
\begin{itemize}
  \item about 30\% of taught step lines were stored wrong;
  \item the gains came from about 225 English strings in Rust (cue lists, prepositions, framing);
  \item LLM style judges had pulled the work toward polishing wording rather than content.
\end{itemize}

\subsection{What 3.0 changes}
3.0 keeps the symbolic core and changes four things:
\begin{enumerate}
  \item \textbf{Content, not polish.} An answer is a list of relation lines, one fact per line. The measure of record is an exact fact-and-relation check, and no style judge is used.
  \item \textbf{Learned language.} English becomes facts through averaged-perceptron taggers trained offline on teach lines aligned to their facts. The teacher (Haiku) reads only the lines the model is unsure of, and each such answer becomes a training pair.
  \item \textbf{No English in agent code.} A test fails if any agent crate contains a list of English words.
  \item \textbf{Measured transfer.} Adaptation uses learned item functions and stored cases, is gated by support, and states a gap when it has none.
\end{enumerate}
